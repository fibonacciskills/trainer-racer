While I love zwift, i think there should be actual games that work with indoor cycling trainers to make things more fun for me, my kids and maybe others! 

It should detect your trainer, and you can use arrow keys to go up and down to avoid obstacles... will work on adding zwift controls etc and shifting if possible (probably not).

But it's been fun to talk to my kids about it to help create it (with cursor mostly) 

Graphics almost as good as zwift's already! 

To run, download as a zip or github, then enter your terminal and navigate to that directory (cd Github, cd trainer-racer) then type python3 -m http.server 8000

Open your browser and go to http://localhost:8000/ and then you should be able to play!
